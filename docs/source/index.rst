Welcome to AIND Metadata Service
================================

AIND Metadata Service is a REST service that aggregates metadata from multiple backend sources
and returns standardized `aind-data-schema <https://github.com/AllenNeuralDynamics/aind-data-schema>`_
models.

The service is composed of containerized microservices — one per data source —
that are orchestrated together to compile a unified metadata response for a given
subject or asset.
